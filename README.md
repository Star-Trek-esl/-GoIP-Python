# -Автоматизация отправки сообщений через GoIP на Python -
GoIP - это программное обеспечение, которое обеспечивает передачу голосовых данных по сети Интернет. Нужен для соединения между сетями GSM и VoIP и используется для передачи голосового трафика через IP-сеть, что позволяет сократить затраты на междугородные и международные звонки. GoIP также может быть использован для организации виртуальной IP-телефонии и для работы с голосовыми шлюзами. Когда SIM карта вставлена в GoIP, пользователи могут регистрировать GSM телефон в VoIP системе. Через Hybetone GoIP GSM  можно реализовать как входящий, так и исходящий траффик звонков между GSM и VoIP сетями.

Программный код выполняет следующие функции:

1. Отправлять сообшения и записывать уже отправленные сообщений в csv файл с датой и статусом отправки

2. Отправлять USSD команды

3. Просмотр и запись смс почты в csv файл

4. Цикл отправки сообщей из csv файла с последующей их записью и удалений уже отрпавленых

5. Цикл проверка баланса и при его изменении запись в csv файл
